# WhatsApp Integration for R.E.M.I

## 🚀 Quick Start

### 1. Deploy the System
```bash
# Run the deployment script
./scripts/deploy_whatsapp.sh

# This will:
# - Check prerequisites (Docker, Docker Compose)
# - Start Matrix homeserver, PostgreSQL, Redis
# - Create Matrix admin user
# - Start R.E.M.I application with WhatsApp integration
# - Test all endpoints
```

### 2. Test WhatsApp Connection
```bash
# Run the test script
python3 scripts/test_whatsapp_connection.py

# This will:
# - Test API endpoints
# - Request WhatsApp connection
# - Generate QR code
# - Monitor connection status
```

### 3. Connect Your WhatsApp
1. **Open WhatsApp** on your mobile device
2. **Go to Settings → Linked Devices**
3. **Tap "Link a Device"**
4. **Scan the QR code** generated by the test script
5. **Wait for connection** (usually 10-30 seconds)

### 4. Send Test Messages
- Send a WhatsApp message to yourself or a contact
- Check http://localhost:8000/api/v1/messages?platform=whatsapp
- Messages should appear within 2 seconds!

## 📋 Prerequisites

- **Docker** and **Docker Compose** installed
- **At least 2GB RAM** available
- **Ports 8000, 8008, 5432, 6379** available
- **WhatsApp mobile app** with "Link Device" feature
- **Internet connection** for pulling Docker images

## 🏗️ Architecture Overview

```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   WhatsApp      │    │  mautrix-whatsapp│    │   Matrix        │    │   R.E.M.I       │
│   Mobile App    │◄──►│     Bridge       │◄──►│  Homeserver     │◄──►│   System        │
└─────────────────┘    └──────────────────┘    └─────────────────┘    └─────────────────┘
```

### How It Works

1. **WhatsApp Bridge**: `mautrix-whatsapp` containers connect to WhatsApp Web protocol
2. **Matrix Homeserver**: Synapse server manages Matrix protocol and rooms
3. **R.E.M.I Integration**: Processes Matrix events and converts to R.E.M.I format
4. **Message Flow**: WhatsApp → Bridge → Matrix → R.E.M.I → AI Processing

## 🔧 Manual Deployment

If you prefer manual setup:

### 1. Start Core Services
```bash
docker-compose -f docker/whatsapp-bridge-manager.yml up -d matrix postgres redis
```

### 2. Create Matrix User
```bash
docker exec -it remi_matrix register_new_matrix_user -c /data/homeserver.yaml http://localhost:8008
```

### 3. Get Access Token
```bash
curl -X POST http://localhost:8008/_matrix/client/r0/login \
  -H "Content-Type: application/json" \
  -d '{"type": "m.login.password", "user": "your_username", "password": "your_password"}'
```

### 4. Update Environment
```bash
# Edit .env file with Matrix access token and user ID
MATRIX_ACCESS_TOKEN=syt_your_token_here
MATRIX_USER_ID=@your_username:matrix.remi.local
```

### 5. Start R.E.M.I
```bash
docker-compose -f docker/whatsapp-bridge-manager.yml up -d remi-app
```

## 🔍 Troubleshooting

### Common Issues

#### 1. Matrix not starting
```bash
# Check logs
docker logs remi_matrix

# Common fixes:
# - Ensure port 8008 is available
# - Check homeserver.yaml syntax
# - Restart container: docker restart remi_matrix
```

#### 2. QR code not generating
```bash
# Check R.E.M.I logs
docker logs remi_app

# Check Matrix connectivity
curl http://localhost:8008/_matrix/client/versions

# Common fixes:
# - Verify Matrix access token in .env
# - Restart R.E.M.I: docker restart remi_app
```

#### 3. Messages not syncing
```bash
# Check bridge logs
docker ps | grep whatsapp
docker logs whatsapp_bridge_[user_id]

# Common fixes:
# - Ensure WhatsApp is still connected on mobile
# - Check bridge container is running
# - Restart bridge via API: POST /api/whatsapp/bridges/{id}/cleanup
```

#### 4. Bridge containers not spawning
```bash
# Check Docker socket access
docker ps

# Ensure Docker daemon is running
sudo systemctl start docker  # Linux
# or restart Docker Desktop on macOS/Windows

# Check R.E.M.I has Docker access
docker logs remi_app | grep -i docker
```
